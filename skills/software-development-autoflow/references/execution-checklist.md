# 执行检查清单

> 性质：**纯引用式执行导航工具**，不定义、不复述任何机制——每行仅为「原子动作名 + 权威定义处指针」；动作的触发条件、规则细节、例外与处置出口一律以指针指向的组件原文为准（冲突规则见 `SKILL.md` §2）
> 用途：Main Agent 调度时按节顺序逐项核对「该动作是否已执行、定义处是否已查阅」，降低跨组件规则定位负担；勾选状态不进任何落盘产物，仅作当次调度参考
> 覆盖：一次新需求完整流水线（启动 → 四阶段 → 交付收尾）+ 断点恢复路径（§8 组）；升级人工、强制确认、事件写入等横切义务不在此展开，分别以《工作模式》§6/§7、各细则 §7.4、《上下文体系》§9 为权威
> 校验规则：任一组件发生章节重编号、章节删除/合并、语义实质变更时，逐行核对涉及行并同步修正指针（与 `cross-reference-index.md` 同批执行）；本表不得被用作组件原文的替代阅读物

## 使用与维护

1. **顺序语义**：§1 → §7 为一次新需求的执行顺序；§8 为续跑场景的替代入口，自「回到主调度循环」起汇入 §2；
2. **勾选语义**：勾选表示「该动作已执行且留痕位置已确认」，不表示「已满足定义处全部条件」——条件核验以指针原文为准；
3. **不增机制**：本表任何行不得被引用为机制依据；发现行内容与指针原文不一致时，以原文为准并立即修正本表；
4. **留痕**：本表的校验结论随当次组件改动记入 `changelog/` 当日文件（与交叉引用索引表同批）。
