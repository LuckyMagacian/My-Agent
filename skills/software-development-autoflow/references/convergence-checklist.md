# 收敛检查清单

> 性质：**纯引用式校验工具**，不定义、不复述任何机制——每行仅为「校验项名 + 权威定义处指针」；校验项的触发条件、规则细节、例外与处置出口一律以指针指向的组件原文为准（冲突规则见 `SKILL.md` §2）
> 用途：仲裁者（Main Agent）在每轮仲裁中逐项核验收敛判定条件是否满足，降低跨条件遗漏风险；勾选状态不进任何落盘产物，仅作当次仲裁参考
> 覆盖：《工作模式》§6 收敛与终止全部判定条件；本表不覆盖异常处理（见《工作模式》§7）、人工确认（见各细则 §7.4）、事件写入（见《上下文体系》§9.4）
> 校验规则：任一组件发生章节重编号、章节删除/合并、语义实质变更时，逐行核对涉及行并同步修正指针（与 `cross-reference-index.md`、`execution-checklist.md` 同批执行）；本表不得被用作组件原文的替代阅读物

## §1 收敛判定必要条件（前置核验）

- [ ] 所有视角评估者均在报告中建议收敛 → 《工作模式》§6.1
- [ ] 各视角评分均 ≥ 收敛阈值（默认 8/10） → 《工作模式》§6.1
- [ ] 阻断级问题清零 → 《工作模式》§6.1
- [ ] 判定基于评估者最新一轮报告（仲裁者不得绕过评估直接判定） → 《工作模式》§6.1
- [ ] 阻断暂缓权检查：Main Agent 自行发现的阻断级问题已处置或暂停收敛 → 《工作模式》§2.2 约束 2

## §2 问题台账核验

- [ ] 台账中阻断级问题均处于「已闭合」状态（含闭合位置与证据引用） → 《工作模式》§6.2
- [ ] 「重要」级问题逐条核验闭合状态并在仲裁记录留痕 → 《工作模式》§6.2
- [ ] 「重要」级问题允许「评分承载」状态收敛（附轮次与评分引用） → 《工作模式》§6.2
- [ ] 追加约束重启时台账随旧轮次转只读归档，重启后新建台账 → 《工作模式》§6.2

## §3 减法轮触发判定（四条件逐项检查）

- [ ] 条件①：连续 2 轮新增行为定义项数 > 删除/合并的行为定义项数（以变更说明项类标注为据） → 《工作模式》§6.4
- [ ] 条件②：同根因复发熔断被触发 → 《工作模式》§6.4
- [ ] 条件③：达迭代上限未收敛且人工裁决选用追加约束重启 → 《工作模式》§6.4
- [ ] 条件④：评分停滞 + 交付物持续增长（优先于停滞检测升级人工路径） → 《工作模式》§6.4
- [ ] 减法轮宣布已写入下一轮整合意见首部 → 《工作模式》§6.4
- [ ] 减法轮内禁止新增条款（等价删除置换，无法置换的升级人工） → 《工作模式》§6.4

## §4 同根因复发熔断判定

- [ ] 同根因标签问题跨轮第 2 次出现（以台账发现轮次计） → 《工作模式》§6.3
- [ ] 熔断触发时整合意见不含「新增守卫/例外/兜底条款」类修改方向 → 《工作模式》§6.3
- [ ] 熔断后修改方向改为模型级修复（消维度/改派生/并机制/压缩语义） → 《工作模式》§6.3
- [ ] 熔断判定与修复方向选择写入仲裁记录 → 《工作模式》§6.3

## §5 停滞检测

- [ ] 连续 2 轮未建议收敛的视角评分无提升（净变化 ≤ 0） → 《工作模式》§6 停滞检测
- [ ] 按视角独立计算，任一未收敛视角满足即触发 → 《工作模式》§6 停滞检测
- [ ] 收敛判定优先于停滞检测 → 《工作模式》§6 停滞检测
- [ ] 减法轮拦截：满足条件④时先触发减法轮，减法轮后评分仍无提升方升级人工 → 《工作模式》§6 停滞检测

## §6 重复问题反思

- [ ] 同一问题位置（或同构问题）连续 2 轮经整合意见回传后仍未解决 → 《工作模式》§6 重复问题反思
- [ ] 仲裁记录含反思段（治标/治本判定、根因判定、修改方向调整结论） → 《工作模式》§6 重复问题反思
- [ ] 方向调整后同一问题仍未解决 → 升级人工 → 《工作模式》§6 重复问题反思

## §7 重规划基线重置

- [ ] 触发式重规划发生后，停滞检测与重复问题计数以重规划轮次为新基线 → 《工作模式》§6 重规划基线重置
- [ ] 同根因复发熔断计数不随基线重置（台账跨轮持久） → 《工作模式》§6 重规划基线重置
- [ ] 重置理由记入仲裁记录 → 《工作模式》§6 重规划基线重置

## §8 收敛加速（整合意见裁剪）

- [ ] 存在「重要」级问题时，整合意见仅回传「阻断」级与「重要」级问题 → 《工作模式》§6 收敛加速
- [ ] 不存在「重要」级问题时，整合意见仅回传「阻断」级问题 → 《工作模式》§6 收敛加速
- [ ] 收敛条件满足时不因「建议」级问题未解决而继续迭代 → 《工作模式》§6 收敛加速

## §9 规划阶段收敛（如启用）

- [ ] 规划阶段复用收敛判定、收敛加速与停滞检测规则 → 《工作模式》§6 规划阶段收敛
- [ ] 同根因复发熔断、减法轮、零增量检验仅适用于执行阶段 → 《工作模式》§6 规划阶段收敛
- [ ] 简洁性审视义务在规划阶段同样履行（仅限清点可删部分，不复核零增量论证） → 《工作模式》§6 规划阶段收敛

## 使用与维护

1. **使用时机**：每轮仲裁中，仲裁者（Main Agent）在完成一致意见合并与冲突裁决后，按 §1 → §9 顺序逐项核验；
2. **勾选语义**：勾选表示「该校验项已核验且结论已记入仲裁记录」，不表示「已满足全部条件」——条件判定以指针原文为准；
3. **不增机制**：本表任何行不得被引用为机制依据；发现行内容与指针原文不一致时，以原文为准并立即修正本表；
4. **留痕**：本表的校验结论随当次组件改动记入 `changelog/` 当日文件（与交叉引用索引表、执行检查清单同批）。
