## 校验规则

1. **触发时机**：任一组件发生章节重编号、章节删除/合并、章节语义实质变更时；
2. **校验动作**：定位本表中该组件作为被引方的全部行，逐行核对引用方原文中对应引用的语义是否仍成立；失效引用随当次修订同步修正引用方（经验教训：修订时须同步检查引用侧文档与图注）；
3. **留痕**：校验完成后更新头部「末次校验」行（日期 + 对应版本集）；当次改动的校验结论记入 `changelog/` 当日文件；
4. **边界**：本表不覆盖组件内部自引用（§N 本文引用）与版本耦合（头部对齐基准行），后者由各文档升版时的基线同步惯例承载。
