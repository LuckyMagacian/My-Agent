## 3. 拆解依据

- 按「盘点 → 规约 → 记录 → 迁移 → 同步」线性拆解：总账覆盖的无失真性依赖盘点的完备性（S1 前置），迁移映射依赖规约形态定型（S4 依赖 S2/S3）——替代拆法（先迁移后规约）会使指针改造失去目标形态依据，已排除；
- S5 独立为定稿后步骤：引用侧同步属元数据级改动，若在评估前执行，评估未收敛返工会牵连多文件回退，成本不对称；
- 总账采用「摘要 + 指针」而非全文吸收：细节全文已在 changelog 明细，吸收即双写，违反约束①——取舍理由在此显式留痕。
