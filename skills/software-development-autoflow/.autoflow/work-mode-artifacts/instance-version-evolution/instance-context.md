# 实例上下文 —— version-evolution 组件建立

> 实例名：instance-version-evolution
> 模式依据：`references/work-mode.md`《执行者-评估者-仲裁者工作模式》v1.6.2
> 实例化时间：2026-08-07（会话日期口径）

## 任务指令（四要素）

- **目标**：建立 `references/version-evolution.md` 版本迭代组件——记录 skill 全部版本变更（总账）、规约 changelog 的用法、迁移现有组件中版本演进相关信息至该组件；并在定稿后完成引用侧同步（SKILL.md 登记、各组件头部留痕指针、《上下文体系》§12、交叉引用索引）。
- **约束**：① 与 changelog/ 目录分工为「总账 + 明细分层」——组件承载规约与总账（每版本一行摘要），changelog/ 继续作为按日明细留痕库，总账行指向明细文件，细节不双写（单一事实来源）；② 组件登记为原子组件（SKILL.md §2 登记表）；③ 组件不重定义其他组件机制（冲突规则 SKILL.md §2）；④ 用户决策留痕：直接补丁流程被否决，本组件须经 work-mode 双视角评估定稿；⑤ 不参考任何外部文档与既有 skill。
- **验收标准**：① 组件含规约段（版本号规则、升版触发、引用侧同步义务、changelog 用法）且与既有惯例无矛盾；② 总账覆盖全部 8 份文档的现行版本与历史版本摘要，无失真无遗漏（与 changelog/2026-08-07.md 逐条可比对）；③ 迁移后各组件头部留痕指针指向新组件，changelog 明细原位保留；④ 引用侧同步完整（登记表、§12、索引末次校验）；⑤ 双视角评估收敛（各 ≥8/10、零阻断、均建议收敛）。
- **范围**：交付物 = `references/version-evolution.md` 单文件（首轮）；引用侧同步在定稿后由 Main Agent（仲裁者侧）执行，不属执行者交付物本体但属任务目标。
