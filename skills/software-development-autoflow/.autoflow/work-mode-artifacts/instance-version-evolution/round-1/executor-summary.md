# 交付物摘要 —— version-evolution.md 组件（round-1）

本交付物为版本迭代原子组件 `references/version-evolution.md` v1.0 全文（交付物本体见同目录 executor-deliverable.md 第 2 段）：

- **核心目标**：建立 skill 组件体系版本演进事务的唯一权威文档，与 changelog/ 目录「总账 + 明细分层」分工，细节不双写；
- **§1 定位**：原子组件（版本演进治理），不定义不复述流水线机制；
- **§2 版本规约**：语义化版本三段式；机制增量直接补丁升版；纯元数据同步不升机制版本（SKILL.md 例外：每次改动升号）；总账行粒度以源明细形态为准、无失真优先；引用侧五类同步点位同批义务；
- **§3 changelog 用法**：按改动日期命名、一次改动全量条目入当日文件、多批以触发段分列（含拒绝项原则性理由）、迁移条目零失真格式、文档头部仅留版本与对齐基准；
- **§4 总账**：七份版本文档全部历史版本 + 本文自记行 + 两个工具文件建立事件，每版本一行摘要 + 明细指针；
- **§5 治理流程**：直接补丁为默认修订流程，重大新增组件/机制组走 work-mode 实例评估；决策留痕义务（拒绝项原则性理由、不一致处置口径）；
- **关键决策**：规划阶段两项重要裁定固化入规约（P2-1 不升机制版本、P2-4 行粒度口径）；
- **主要变更**：首轮产出，无删除/合并项，无未落实项，无计划偏离。
