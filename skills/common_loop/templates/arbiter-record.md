# 模板：arbiter-record

## 填充说明

| 占位符 | 填充者 | 填充源 | 时机 |
|--------|--------|--------|------|
| `{n}` | 主循环 | tasks.md 任务 ID | 每次内层质量轮仲裁 |
| `{attempt}` | 主循环 | task.attempt（外层计数） | 仲裁时 |
| `{q_round}` | 主循环 | task.quality_round（内层计数） | 仲裁时 |
| `{score}` | 主循环 | reviewer 报告评分 | 仲裁时 |
| `{threshold}` | 主循环 | 注入/默认 8 | 仲裁时 |
| `{建议}` | 主循环 | reviewer 收敛建议 | 仲裁时 |
| `{阻断数}` | 主循环 | reviewer 报告阻断级问题数 | 仲裁时 |

## 2. 评分与收敛条件核验

| 项 | 值 | 阈值 | 满足？ |
|----|----|----|--------|
| 评分 | {score}/10 | ≥ 8 | ✅/❌ |
| 收敛建议 | {建议} | "建议收敛" | ✅/❌ |
| 阻断级问题 | {阻断数} | = 0 | ✅/❌ |
| 问题台账核验 | 见 §6 | 阻断/重要级已闭合 | ✅/❌ |

**综合**：✅ 收敛 / ❌ 未收敛

### 2.1 停滞检测
- 上轮评分：{prev_score}（无则填 N/A）
- 本轮评分：{score}
- 净变化：{delta}
- 触发停滞（连续 2 轮 ≤ 0）：✅/❌

### 2.2 同根因复发熔断判定
- 本轮是否含已存在根因标签：是/否
- 若有，对应历史条目 ID：{issue_id}
- 熔断触发（跨 quality_round 第 2 次出现）：✅/❌
- 触发时修复方向（仅模型级）：{消维度/改派生/并机制/其他}

### 2.3 减法轮触发判定（任一条件为真则触发）
- 条件① 评分停滞 + 交付物持续增长（连续 2 轮新增>删除）：✅/❌
- 条件② 同根因熔断已触发：✅/❌
- 条件③ 外层 attempt 阻断（attempt==3 或 6 阻断分析触发时）：✅/❌
- 触发：✅/❌
- 触发条件编号：{1/2/3}

## 3. 一致意见合并
- reviewer 直接指出的问题（按根因标签聚合）：
  - 标签 {tag}：{问题摘要} × {n}
  - 标签 {tag}：{问题摘要} × {n}

## 4. 冲突裁决（如有）
- 冲突项：{摘要}
- 双方意见：{A} vs {B}
- 裁决依据：{优先级阶梯 ①正确性 > ②需求合规 > ③技术可行性 > ④体验}
- 采纳结论：{A/B/部分采纳}

### 4.1 优先级阶梯引用
| 优先级 | 类别 | 裁决规则 |
|--------|------|---------|
| ① | 正确性与安全 | 一票优先，不权衡，必须满足 |
| ② | 需求与验收合规 | 以需求规格为准；若不可行产出澄清项 |
| ③ | 技术可行性与质量 | 满足①②前提下，成本更低/风险更小优先 |
| ④ | 体验与优化项 | 记录为建议，不阻断收敛 |

## 5. 权衡项处置
- {权衡项}：自动采纳（留痕）/ 升级人工
- 依据：{单视角内部/≤2处/不改变对外结构 → 自动采纳；否则升级}

## 6. 问题台账更新
- 本轮新增条目：{n}（见 issue-log.md 追加）
- 闭合条目：{n}（引用 ID + 闭合位置 + 证据）
- 评分承载条目（重要级）：{n}（引用 ID + 轮次）

## 7. 零增量审计
- executor 本轮新增条款：{n}
- 论证成立：{n} | 不成立：{n} | 拒绝纳入：{n}
- 拒绝项：{条款名 + 理由}

## 8. 整合结论（三态）
- **✅ 确认收敛** → attempt 通过，task.completed
- **❌ 整合意见**（未收敛）→ 进入下一 quality_round（q_round < N）
- **⚠️ 升级人工** → 内层耗尽或权衡项无法裁决

### 8.1 整合意见（如未收敛）
按收敛加速规则回传：
- 阻断级问题：{逐条，含位置+级别+来源}
- 重要级问题：{逐条，含位置+级别+来源}
- 建议级问题：暂不纳入回传（记录于此）
- 减法轮宣布（如触发）：下一 quality_round 修订仅限删除/合并/简化

### 8.2 减法轮约束（如宣布）
- 仅限删除、合并、简化
- 不得新增任何条款
- 任务指令/整合意见要求的新增须以等价删除置换（等价性按 §4.1 阶梯判定）
- 删除/合并项逐条附零增量论证

## 9. 主循环仲裁约束自检

- [ ] 优先级阶梯未外置
