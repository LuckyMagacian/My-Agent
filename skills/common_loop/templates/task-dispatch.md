## 填充说明

| 占位符 | 填充者 | 填充源 | 时机 |
|--------|--------|--------|------|
| `{n}` | 主循环 | tasks.md 任务 ID | dispatch_executor 时 |
| `{日期}` | 主循环 | run_dir 路径 | dispatch_executor 时 |
| `{目标}` | 主循环 | goal.md 标题 | dispatch_executor 时 |
| `{attempt}` | 主循环 | task.attempt（外层计数） | dispatch_executor 时 |
| `{q_round}` | 主循环 | task.quality_round（内层计数） | dispatch_executor 时 |
| `{失败原因}` | 主循环 | task.failure_reason | 重试时（attempt>1） |
| `{失败历史}` | 主循环 | task.failure_history（reports 路径列表） | 重试时（attempt>1） |
| `{整合意见}` | 主循环 | 上轮 arbiter 整合意见 | 内层 q_round>1 时 |

# 任务下发：T{n}（外层 attempt {attempt}, 内层 q{q_round}）

## 任务来源
> **模式说明**：
> - **self 模式**（executor 自执行）：executor 读取 `.ai/docs/loop-runs/{日期}-{目标}/tasks.md` 中 **T{n}** 任务条目
> - **adapter 模式**（转交技术域 agent）：executor 已用 `pack_task_entry` 将任务条目内容内联注入 `{task_content}`，被转交 agent 无需读取 tasks.md、无需了解 common_loop 格式

self 模式：读取 `.ai/docs/loop-runs/{日期}-{目标}/tasks.md` 中 **T{n}** 任务条目（含描述/预期产出/完成标准/依赖）
adapter 模式（内联内容）：{task_content}

## 执行要求
- 完成标准：以 tasks.md 中 T{n} 的「完成标准」为准
- 失败原因（重试时）：{失败原因}（逐条修正）
- 失败历史（重试时）：{失败历史}（历史 reports 路径，供参考避免重复尝试）
- 整合意见（内层 q_round>1 时）：{整合意见}（逐条对照修正）
- 减法轮约束（如宣布）：{减法轮约束}（仅限删除/合并/简化，不得新增）
- 约束：组合>扩展>修改，最小改动，非局部改动提示影响范围

## 输出契约（5 段交付物）

executor 必须按以下 5 段结构产出（顺序固定），缺段视为不合格：

1. **标题**：一句话概括本次产出的目标
2. **正文**：交付物主体（代码/文档/配置变更）
3. **变更说明**（含防膨胀元数据）：
   - **3.1 新增项**（行为定义项）—— 每条附**零增量论证**：「删除该条款后是否损失行为定义？」+ 理由
   - **3.2 删除/合并项** —— 每条附：删除动机（按简洁性意见/减法轮要求/自主删减）+ 项类标注（行为定义项 / 非行为定义项）
   - **3.3 能力利用声明**（如使用 skill/tool）—— 名称 + 用途 + 产出概要
4. **摘要**：一段话概括交付物的核心内容、关键决策与主要变更
5. **未落实项声明**（可选）—— 对无法落实的整合意见以「未落实项 + 理由」显式声明；未声明者视为已接受全部意见

> **零增量论证**示例：
> - 新增项：「增加超时重试机制」—— 删除后是否损失行为定义？是（远程调用无重试将不可靠）。论证成立。
> - 新增项：「为常量 C 加注释」—— 删除后是否损失行为定义？否（注释不定义行为）。若非减法轮内可纳入；减法轮内拒绝。

> **防膨胀护栏**：
> - 任何新增条款无零增量论证 → arbiter 拒绝纳入本轮交付物
> - 减法轮内新增任何条款（即使有论证）→ 拒绝
> - 减法轮内任务指令/整合意见要求的新增须以等价删除置换，无法置换的升级人工

## 计划偏离声明（如有，按 3 型分类）

若产出与已确认任务说明存在偏离，按类型声明：
- **执行细节型**：不改变任务目标与完成判据，仅实现方式调整 → 自行调整并在变更说明登记，无需事先声明
- **假设失效型**：依赖的前提证据/假设被证伪 → 显式声明 + 理由；arbiter 核验成立触发外层重试
- **目标失效型**：任务指令的目标/约束/验收标准本身有误 → 显式声明 + 理由；升级人工（主循环无权修改目标）
- 未声明的非执行细节型偏离按过程契约违规退回重出

## 输出契约
- 产出物：5 段交付物（标题/正文/变更说明/摘要/未落实项声明）
- 路径：写入 `run_dir/inner/T{n}/r{attempt}-q{q_round}-deliverable.md`
- 摘要另存：写入 `run_dir/inner/T{n}/r{attempt}-q{q_round}-summary.md`
- ⚠️ 不得自述"完成"——完成由 result_reviewer 经评分+收敛建议判定
