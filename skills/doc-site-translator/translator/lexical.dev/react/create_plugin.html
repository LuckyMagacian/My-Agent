创建 React Plugin

要在 React 中创建自定义 Lexical plugin，您可以开发一个 React 组件并将其作为 LexicalComposer 组件的子组件包含。如果您的 plugin 引入了新节点，请确保这些节点已注册在 initialConfig.nodes 数组中。

基本 Plugin 结构 #

Plugin 通过作为 LexicalComposer 组件的子组件渲染来集成，该组件提供了访问 editor 实例所需的 React Context。在 plugin 中注册的命令可以通过派发来触发，例如从按钮点击中派发。

以下是一个基本的 plugin 结构示例：

// MyLexicalPlugin.js

export function MyLexicalPlugin(props) {
  const [editor] = useLexicalComposerContext();
  // ...plugin 逻辑
}

访问 Editor 实例 #

LexicalComposer 通过 React Context 提供对底层 LexicalEditor 实例的访问，您可以使用 useLexicalComposerContext hook 在 plugin 组件中访问它。这个 editor 实例允许您的 plugin 使用 Commands 和 Transforms 等 API 与 Lexical 交互。

import {useLexicalComposerContext} from '@lexical/react/LexicalComposerContext';

export function MyLexicalPlugin(props) {
  const [editor] = useLexicalComposerContext();

  // 使用 editor 实例...

  return null;
}

注册命令 #

一个常见的 plugin 模式涉及注册一个命令，当派发该命令时，执行特定操作，例如创建自定义节点并将其插入编辑器中。

import {useLexicalComposerContext} from '@lexical/react/LexicalComposerContext';
import {createCommand} from 'lexical';
import {useEffect} from 'react';

export const MY_CUSTOM_COMMAND = createCommand('MY_CUSTOM_COMMAND');

export function MyLexicalPlugin() {
  const [editor] = useLexicalComposerContext();

  useEffect(() => {
    // 注册命令处理器
    const unregister = editor.registerCommand(
      MY_CUSTOM_COMMAND,
      (payload) => {
        // 处理命令...
        return true;
      },
      0
    );

    return unregister;
  }, [editor]);

  return null;
}

自定义 OnChange Plugin 示例 #

以下示例展示了如何实现一个自定义 React plugin 来监听编辑器状态更新：

function MyOnChangePlugin({ onChange }) {
  const [editor] = useLexicalComposerContext();

  useEffect(() => {
    return editor.registerUpdateListener(({editorState}) => {
      onChange(editorState);
    });
  }, [editor, onChange]);

  return null;
}

然后将其集成到编辑器中：

function Editor() {
  const [editorState, setEditorState] = useState();

  function onChange(editorState) {
    setEditorState(editorState);
  }

  return (
    <LexicalComposer initialConfig={initialConfig}>
      <RichTextPlugin
        contentEditable={
          <ContentEditable
            aria-placeholder={'Enter some text...'}
            placeholder={<div>Enter some text...</div>/>
        }
        ErrorBoundary={LexicalErrorBoundary}
      />
      <HistoryPlugin />
      <MyOnChangePlugin onChange={onChange}/>
    </LexicalComposer>
  );
}

带自定义节点的 Plugin #

以下示例演示了创建自定义 KeywordNode 和 KeywordsPlugin 来检测和高亮编辑器中的特定关键词：

/**
 * 使用方法:
 * 1. 将 KeywordNode 添加到 initialConfig nodes 数组
 *    如果忘记，您将收到错误
 * 2. 将 <KeywordPlugin /> 作为 LexicalComposer 的子组件添加
 *    如果忘记，它将静默不工作
 * 3. 在某处为 '.keyword' 添加 CSS
 */
import type {EditorConfig, LexicalNode, SerializedTextNode} from 'lexical';
import {$create, TextNode} from 'lexical';
import {useLexicalComposerContext} from '@lexical/react/LexicalComposerContext';
import {useLexicalTextEntity} from '@lexical/react/useLexicalTextEntity';
import {useCallback, useEffect} from 'react';

export class KeywordNode extends TextNode {
  $config() {
    return this.config('keyword', {extends: TextNode});
  }

  createDOM(config: EditorConfig): HTMLElement {
    const dom = super.createDOM(config);
    dom.style.cursor = 'default';
    dom.className = 'keyword';
    return dom;
  }

  canInsertTextBefore(): boolean {
    return false;
  }

  canInsertTextAfter(): boolean {
    return false;
  }

  isTextEntity(): true {
    return true;
  }
}

export function $createKeywordNode(keyword: string): KeywordNode {
  return $create(KeywordNode).setTextContent(keyword);
}

export function $isKeywordNode(node: LexicalNode | null | undefined): boolean {
  return node instanceof KeywordNode;
}

const KEYWORDS_REGEX =
  /(^|[^A-Za-z])(congrats|congratulations|mazel tov|mazal tov)($|[^A-Za-z])/i;

export function KeywordsPlugin(): JSX.Element | null {
  const [editor] = useLexicalComposerContext();

  useEffect(() => {
    if (!editor.hasNodes([KeywordNode])) {
      throw new Error('KeywordsPlugin: KeywordNode not registered on editor');
    }
  }, [editor]);

  const $convertToKeywordNode = useCallback(
    (textNode: TextNode): KeywordNode => {
      return $createKeywordNode(textNode.getTextContent());
    },
    [],
  );

  const getKeywordMatch = useCallback((text: string) => {
    const matchArr = KEYWORDS_REGEX.exec(text);

    if (matchArr === null) {
      return null;
    }

    const hashtagLength = matchArr[2].length;
    const startOffset = matchArr.index + matchArr[1].length;
    const endOffset = startOffset + hashtagLength;
    return {
      end: endOffset,
      start: startOffset,
    };
  }, []);

  useLexicalTextEntity<KeywordNode>(
    getKeywordMatch,
    KeywordNode,
    $convertToKeywordNode,
  );

  return null;
}
⚠️ 重要

至关重要的是，验证 plugin 使用的任何自定义节点是否已在编辑器配置中正确注册。如果节点未注册，plugin 可能会抛出错误或静默失败。

注册自定义节点 #

当您的 plugin 引入新节点时，必须在 LexicalComposer 的初始配置中注册它们：

const initialConfig = {
  namespace: 'MyEditor',
  nodes: [KeywordNode], // 注册自定义节点
  theme,
  onError,
};

<LexicalComposer initialConfig={initialConfig}>
  <KeywordsPlugin />
</LexicalComposer>

旧版 Plugins #

旧版 React plugins 可以通过将其作为 composer 的子组件渲染来按原样使用。为了更好的可重用性，考虑将其打包为 extension 或重构为 React 独立。

许多旧的 Lexical plugins 只是简单的 useEffect 包装器，不需要 React。这些可以使用 defineExtension 重构为 extensions，而不需要 React。

// 旧版 CheckListPlugin 示例
export function CheckListPlugin(): null {
  const [editor] = useLexicalComposerContext();
  useEffect(() => {
    return registerCheckList(editor);
  }, [editor]);
  return null;
}

Extension Decorators #

您可以将旧版 React plugin 打包为 extension decorator。这对于渲染不直接与编辑器内容交互的 React 组件非常有用，例如返回 null 或渲染 portals 的组件。

// 这正是您编写旧版 React plugin 的方式
function LogEditorPlugin() {
  const [editor] = useLexicalComposerContext()
  useEffect(() => {
    console.log(editor);
  }, [editor]);
  return null;
}

// 这是如何将 plugin 声明为 extension
// 它依赖 React 并将此 plugin 渲染为 decorator
export const LogEditorExtension = defineExtension({
  name: "@example/LogEditor",
  dependencies: [
    configExtension(ReactExtension, {
      decorators: [<LogEditorPlugin />]
    }),
  ],
});
💡 提示

打包或重构的策略包括使用 Extension Decorators 和 Output Components，以及以 React Independence 为目标。
