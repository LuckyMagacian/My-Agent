React Plugins

Lexical plugins 是 React 包装器，用于向 Lexical 编辑器添加功能。它们利用来自 <LexicalExtensionComposer> 或旧版 <LexicalComposer> context 的 Lexical editor 实例。许多 plugin 需要在 editor 的初始配置中注册其对应的 Lexical nodes。

基本用法 #

以下示例展示了如何使用 LexicalComposer 和多个 plugin 设置基本的 Lexical 编辑器：

import {LexicalComposer} from '@lexical/react/LexicalComposer';
import {PlainTextPlugin} from '@lexical/react/LexicalPlainTextPlugin';
import {ContentEditable} from '@lexical/react/LexicalContentEditable';
import {HistoryPlugin} from '@lexical/react/LexicalHistoryPlugin';
import {OnChangePlugin} from '@lexical/react/LexicalOnChangePlugin';

const initialConfig = {
  namespace: 'MyEditor',
  theme,
  onError,
};

<LexicalComposer initialConfig={initialConfig}>
  <PlainTextPlugin
    contentEditable={<ContentEditable />}
    placeholder={<div>Enter some text...</div>}
  />
  <HistoryPlugin />
  <OnChangePlugin onChange={onChange} />
  ...
</LexicalComposer>;

可用的 Plugins #

@lexical/react 包提供了许多内置 plugin，您可以在编辑器中组合使用：

核心 Plugins #

  • PlainTextPlugin - 提供纯文本编辑功能
  • RichTextPlugin - 提供富文本编辑功能，支持粗体、斜体等格式
  • HistoryPlugin - 启用撤销/重做功能
  • OnChangePlugin - 监听编辑器状态变化
  • AutoFocusPlugin - 自动聚焦编辑器

列表 Plugins # 

import {ListPlugin} from '@lexical/react/LexicalListPlugin';

<ListPlugin
  hasStrictIndent={true}
  shouldPreserveNumbering={true}
/>

ListPlugin 用于在 Lexical 编辑器中启用列表编辑功能。它接受以下可选参数：

  • hasStrictIndent - 当为 true 时，对列表项强制执行严格的缩进规则。默认为 false。
  • shouldPreserveNumbering - 当为 true 时，分割编号列表将保持编号连续性。默认为 false。

协作 Plugin #

CollaborationPlugin 集成 Yjs 实现实时协作编辑。它创建 Yjs 绑定、渲染远程光标，并提供协作撤销/重做功能。

import {CollaborationPlugin} from '@lexical/react/LexicalCollaborationPlugin';
import {WebsocketProvider} from 'y-websocket';
import {Doc} from 'yjs';

function createProvider(id, yjsDocMap) {
  const doc = new Doc();
  yjsDocMap.set(id, doc);
  return new WebsocketProvider('ws://localhost:1234', id, doc);
}

<CollaborationPlugin
  id="my-document"
  providerFactory={createProvider}
  shouldBootstrap={true}
  username="Alice"
  cursorColor="#FF0000"
/>

链接 Plugins # 

import {ClickableLinkPlugin} from '@lexical/react/LexicalClickableLinkPlugin';

<ClickableLinkPlugin
  disabled={false}
  newTab={true}
/>

ClickableLinkPlugin 启用编辑器中可点击的链接。参数说明：

  • disabled - 如果为 true，plugin 将被禁用。
  • newTab - 如果为 true，链接将在新标签页中打开。默认为 true。

自动嵌入 Plugin #

LexicalAutoEmbedPlugin 监听粘贴的 AutoLink nodes，当匹配嵌入配置时（例如 YouTube、Twitter URLs），显示菜单提供将链接替换为嵌入节点的选项。

interface CustomEmbedConfig extends EmbedConfig<{
  domain: string;
  oid?: string;
}> {
  // 显示图标
  icon?: JSX.Element;
  // 描述
  description?: string;
};

return (
  <LexicalAutoEmbedPlugin<CustomEmbedConfig>
    embedConfigs={EmbedConfigs}
    getMenuOptions={getMenuOptions}
  />
);

EditorRefPlugin #

使用此 plugin 可以在 LexicalComposer 外部访问 editor 实例。这对于需要在 React 树中位于 LexicalComposer 外部的按钮或其他 UI 组件非常有用，这些组件需要更新或读取 EditorState。

<EditorRefPlugin
  editorRef={(instance) => {
    // 获取 editor 实例
  }}
/>

参数说明：

  • editorRef - 一个 ref 对象或回调函数，用于接收 editor 实例。

NodeEventPlugin #

一个特定于 React 的 plugin，简化了向 Lexical 编辑器中特定节点类型附加事件监听器的过程。它抽象了 mutation listener 和元素注册的复杂性。

<LexicalComposer>
  <NodeEventPlugin
    nodeType={LinkNode}
    eventType={'click'}
    eventListener={(e: Event) => {
      alert('Nice!');
    }}
  />
</LexicalComposer>

延迟加载 #

Lexical React plugins 是 React 组件，这使得它们高度可组合。此外，如果需要，您可以延迟加载 plugins，这样您只需在实际使用时才支付 plugins 的成本。

import {lazy, Suspense} from 'react';

const MyLazyPlugin = lazy(() => import('./MyLazyPlugin'));

function Editor() {
  return (
    <LexicalComposer initialConfig={initialConfig}>
      <Suspense fallback={null}>
        <MyLazyPlugin />
      </Suspense>
    </LexicalComposer>
  );
}
💡 提示

在支持延迟加载的框架中，您可以将 Lexical plugins 延迟到用户实际与编辑器交互时再加载——这可以极大地帮助提高性能。
