快速开始（Vanilla JS）

本节介绍如何独立于任何框架或库使用 Lexical。如果您打算在 React 应用中使用 Lexical，建议查看 Getting Started with React 页面。

创建编辑器并使用它 #

使用 Lexical 时，通常会使用单个编辑器实例。编辑器实例可以被视为负责将 EditorState 与 DOM 连接起来的组件。编辑器也是您可以注册自定义节点、添加监听器和变换的地方。

编辑器实例可以从 lexical 包创建，并接受一个可选的配置对象，用于设置主题和其他选项：

import {createEditor} from 'lexical';

const config = {
  namespace: 'MyEditor',
  theme: {
    ...
  },
  onError: console.error
};

const editor = createEditor(config);

一旦您有了编辑器实例，当准备好时，您可以将编辑器实例与文档中的 content editable <div> 元素关联起来：

const contentEditableElement = document.getElementById('editor');

editor.setRootElement(contentEditableElement);

如果您想从元素中清除编辑器实例，可以传递 null。或者，如果需要，您可以切换到另一个元素，只需将替代元素引用传递给 setRootElement()。

使用编辑器状态 #

在 Lexical 中，真实来源不是 DOM，而是 Lexical 维护并与编辑器实例关联的底层状态模型。您可以通过调用 editor.getEditorState() 从编辑器获取最新的编辑器状态。

编辑器状态可以序列化为 JSON，编辑器实例提供了一个有用的方法来反序列化字符串化的编辑器状态。

const stringifiedEditorState = JSON.stringify(editor.getEditorState().toJSON());

const newEditorState = editor.parseEditorState(stringifiedEditorState);

更新编辑器状态 #

虽然使用 @lexical/rich-text 或 @lexical/plain-text 辅助包时可能不需要，但对于程序化内容修改以及自定义编辑器微调仍然相关。

有几种更新编辑器实例的方法：

  • 使用 editor.update() 触发更新
  • 通过 editor.setEditorState() 设置编辑器状态
  • 通过 editor.registerNodeTransform() 作为现有更新的一部分应用更改
  • 使用命令监听器，通过 editor.registerCommand(EXAMPLE_COMMAND, () => {...}, priority)

更新编辑器最常用的方法是使用 editor.update()。调用此函数需要传入一个函数，该函数将提供访问底层编辑器状态的权限以进行修改。当开始新的更新时，当前编辑器状态会被克隆并用作起点。从技术角度来看，这意味着 Lexical 在更新期间利用了一种称为双缓冲的技术。有一个编辑器状态表示屏幕上当前的内容，另一个进行中的编辑器状态表示未来的更改。

创建更新通常是一个异步过程，允许 Lexical 将多个更新批量合并到一个更新中——提高性能。当 Lexical 准备将更新提交到 DOM 时，更新中的底层更改和变化将形成一个新的不可变编辑器状态。调用 editor.getEditorState() 将返回基于更新更改的最新编辑器状态。

以下是如何更新编辑器实例的示例：

import {$getRoot, $getSelection, $createParagraphNode, $createTextNode} from 'lexical';

// 在 `editor.update` 内部，您可以使用特殊的 $ 前缀辅助函数。
// 这些函数不能在闭包外部使用，如果尝试会出错。
// （如果您熟悉 React，可以想象这有点像在 React 函数组件外部使用 hook）。

editor.update(() => {
  // 从 EditorState 获取 RootNode
  const root = $getRoot();

  // 从 EditorState 获取 selection
  const selection = $getSelection();

  // 创建新的 ParagraphNode
  const paragraphNode = $createParagraphNode();

  // 创建新的 TextNode
  const textNode = $createTextNode('Hello world');

  // 将文本节点附加到段落
  paragraphNode.append(textNode);

  // 最后，将段落附加到根节点
  root.append(paragraphNode);
});

请注意，核心库（'lexical' 包）不会监听任何命令或对用户事件做出响应来执行编辑器状态更新。 为了在编辑器中看到文本和其他内容，您需要注册命令监听器并在回调中更新编辑器。Lexical 提供了一些辅助包，可以轻松地为纯文本或富文本体验绑定许多基本命令。

如果您想知道编辑器何时更新以便对更改做出反应，可以向编辑器添加更新监听器，如下所示：

editor.registerUpdateListener(({editorState}) => {
  // 最新的 EditorState 可以作为 `editorState` 找到。
  // 要读取 EditorState 的内容，请使用以下 API：

  editorState.read(() => {
    // 就像 editor.update()，.read() 需要一个闭包，您可以在其中使用
    // $ 前缀的辅助函数。
  });
});
