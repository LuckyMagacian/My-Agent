Lexical Developer Tools

浏览器扩展 #

调试使用 Lexical 构建的网站最简单的方法是安装 Lexical Developer Tools 浏览器扩展。它支持以下主流浏览器：

Chrome Web Store
Edge Add-ons
Firefox Add-ons
Mac App Store

现在，如果您访问使用 Lexical 构建的网站（例如 https://playground.lexical.dev/），您将在浏览器的开发者工具窗口中看到 Lexical 面板。
