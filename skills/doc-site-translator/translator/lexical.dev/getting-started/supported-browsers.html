支持的浏览器

注意：Lexical 不支持 Internet Explorer 或旧版本的 Edge。

  • Firefox 115+
  • Chrome 86+（以及其他基于 Chrome 86+ 的浏览器，如 Android Chrome 86+、Edge 86+ 和 Opera 72+）
  • Safari 15+（iOS 15+、iPad OS 15+）
