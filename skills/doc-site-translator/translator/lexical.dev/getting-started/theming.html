主题

Lexical 通过提供一种传递可定制主题对象的方式，将 CSS 类名映射到编辑器创建时，使主题设置变得简单。以下是纯文本主题的示例：

const exampleTheme = {
  paragraph: 'editor-paragraph',
};

在您的 CSS 中，您可以添加类似以下的内容：

.editor-placeholder {
  color: #999;
  overflow: hidden;
  position: absolute;
  top: 15px;
  left: 15px;
  user-select: none;
  pointer-events: none;
}

.editor-paragraph {
  margin: 0 0 15px 0;
  position: relative;
}

要应用它，您需要将其传递给编辑器实例。如果您使用像 React 这样的框架，可以通过将其作为 initialConfig 的属性传递给 <LexicalComposer> 来完成，如下所示：

import {LexicalComposer} from '@lexical/react/LexicalComposer';
import {PlainTextPlugin} from '@lexical/react/LexicalPlainTextPlugin';
import {ContentEditable} from '@lexical/react/LexicalContentEditable';
import {exampleTheme} from './exampleTheme';
import {LexicalErrorBoundary} from '@lexical/react/LexicalErrorBoundary';

const initialConfig = {namespace: 'MyEditor', theme: exampleTheme};

export default function Editor() {
  return (
    <LexicalComposer initialConfig={initialConfig}>
      <PlainTextPlugin
        contentEditable={
          <ContentEditable
            aria-placeholder={'Enter some text...'}
            placeholder={<div className="editor-placeholder">Enter some text...</div>}
          />
        }
        ErrorBoundary={LexicalErrorBoundary}
      />
    </LexicalComposer>
  );
}

如果您使用 vanilla JS，可以将其传递给 createEditor() 函数，如下所示：

import {createEditor} from 'lexical';

const editor = createEditor({
  namespace: 'MyEditor',
  theme: exampleTheme,
});
