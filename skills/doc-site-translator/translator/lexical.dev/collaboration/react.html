Collaboration (React)

本指南将帮助您在 React 应用中使用 Lexical 设置实时协作编辑功能。

快速开始 #

要在 React 中启用协作编辑，请安装必要的依赖项：

$ npm i -S @lexical/react @lexical/yjs lexical react react-dom y-websocket yjs

启动 WebSocket 服务器 #

运行 WebSocket 服务器以启用不同浏览器客户端之间的通信。此设置使用 y-websocket，并支持持久化以在服务器重启之间保存 Yjs 文档：

$ HOST=localhost PORT=1234 YPERSISTENCE=./yjs-wss-db npx y-websocket

基本设置 #

在 React 中设置协作编辑器时，editorState 应在 LexicalComposer 配置中初始化为 null。这表示 collaboration plugin 管理编辑器的初始状态，防止冲突。

import {LexicalComposer} from '@lexical/react/LexicalComposer';
import {RichTextPlugin} from '@lexical/react/LexicalRichTextPlugin';
import {ContentEditable} from '@lexical/react/LexicalContentEditable';
import {CollaborationPlugin} from '@lexical/react/LexicalCollaborationPlugin';
import {WebsocketProvider} from 'y-websocket';
import {Doc} from 'yjs';

const initialConfig = {
  namespace: 'CollaborativeEditor',
  editorState: null,  // 重要：让 collaboration plugin 管理初始状态
  theme,
  onError,
};

function createProvider(id, yjsDocMap) {
  const doc = new Doc();
  yjsDocMap.set(id, doc);
  return new WebsocketProvider('ws://localhost:1234', id, doc);
}

function CollaborativeEditor() {
  return (
    <LexicalComposer initialConfig={initialConfig}>
      <RichTextPlugin
        contentEditable={<ContentEditable />}
        placeholder={<div>开始协作编辑...</div>}
      />
      <CollaborationPlugin
        id="my-document"
        providerFactory={createProvider}
        shouldBootstrap={true}
        username="Alice"
        cursorColor="#FF0000"
      />
    </LexicalComposer>
  );
}

Yjs Providers #

Yjs providers 处理客户端通信、awareness 管理和离线数据存储的复杂性，使它们成为协作应用的理想起点。您可以在 Yjs 官网找到官方推荐的 providers 列表。

常用的 providers 包括：

  • y-websocket - 基于 WebSocket 的 provider，适合实时协作
  • y-indexeddb - 浏览器本地持久化，支持离线编辑
  • WebrtcProvider - 基于 WebRTC 的点对点通信
  • Hocuspocus - 企业级 WebSocket 服务器

CollaborationPlugin 参数 #

参数 类型 说明
id string 文档唯一标识符
providerFactory function 创建 Yjs provider 的工厂函数
shouldBootstrap boolean 是否在连接时初始化文档内容
username string 当前用户的显示名称
cursorColor string 当前用户的光标颜色

远程光标 #

CollaborationPlugin 会自动渲染远程用户的光标和选区。每个用户的光标颜色可以通过 cursorColor 参数设置，用户名通过 username 参数显示。

Collaboration Context #

Collaboration context 提供用户相关信息和 Yjs 文档映射：

interface CollaborationContextType {
  color: string;           // 用户光标颜色
  isCollabActive: boolean; // 协作是否激活
  name: string;            // 用户名称
  yjsDocMap: Map<string, Doc>;  // Yjs 文档映射
}

协作相关命令 #

Lexical Yjs 提供了一些命令来控制连接状态：

  • TOGGLE_CONNECT_COMMAND - 切换 Yjs provider 的连接状态
  • CONNECTED_COMMAND - 指示 Yjs provider 是否已连接
// 断开连接
editor.dispatchCommand(TOGGLE_CONNECT_COMMAND, false);

// 重新连接
editor.dispatchCommand(TOGGLE_CONNECT_COMMAND, true);

Yjs Binding #

createBinding() 函数初始化并返回一个 Yjs binding 实例。此 binding 将 Lexical 编辑器连接到 Yjs 文档，实现实时协作。

import {createBinding} from '@lexical/yjs';

const binding = createBinding(
  editor,      // Lexical editor 实例
  provider,    // Yjs provider 实例
  id,          // 唯一标识符
  doc,         // Yjs 文档
  docMap,      // 文档映射
  excludedProperties  // 可选：排除同步的属性
);

实验性 V2 Binding #

Lexical 提供了实验性的 V2 binding，用于更高效的同步：

<CollaborationPluginV2__EXPERIMENTAL
  // V2 特定参数
/>
⚠️ 注意

V2 binding 是实验性功能，API 可能会在未来版本中更改。

构建协作 Plugins #

虽然 Lexical Playground 的协作 plugins 不是生产就绪的，但它们可以作为 Lexical 协作能力的优秀示例，并为开发提供坚实的起点。

协作撤销/重做 #

CollaborationPlugin 提供协作撤销/重做历史。在协作环境中，timeout 对撤销合并至关重要，通常间隔为 1 到 5 秒。较长的 timeout 可以改善用户体验，特别是在协作环境中，通过为输入提供更多时间并减少其他客户端编辑的干扰。

历史记录设置 #

Timeouts 对撤销合并至关重要，间隔通常在 1 到 5 秒之间。较长的 timeout 可以改善用户体验，特别是在协作环境中，通过允许更多时间进行输入并减少其他客户端编辑带来的干扰。适当的 timeout 持续时间取决于用户期望和协作功能。

💡 提示

Extensions 促进不同 extensions 之间的功能共享和增强，例如集成协作工具或添加 markdown 导入/导出能力。它们提供特定于 extension 的 context，范围限定到一个编辑器，克服了旧版 plugins 的限制和 React context providers 所需的严格层级结构。
