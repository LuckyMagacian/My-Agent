DecoratorNode（装饰器节点）

概述

DecoratorNode 是 Lexical 中一种特殊的节点类型，用于在编辑器中嵌入 React 组件或其他框架组件。 与普通节点不同，DecoratorNode 允许您在编辑器内容中渲染任意 UI 组件，同时保持与编辑器状态管理的一致性。

什么是 DecoratorNode？

在 Lexical 中，大多数节点（如 TextNode、ParagraphNode）直接渲染为 DOM 元素。 但有时我们需要在编辑器中嵌入更复杂的 UI，例如：

  • 嵌入图片或视频播放器
  • 嵌入表格组件
  • 嵌入代码编辑器（如 Monaco Editor）
  • 嵌入社交媒体预览卡片
  • 嵌入日期选择器或表单控件

DecoratorNode 正是为这类需求设计的。它允许节点返回一个 React 组件（或其他框架组件）， 由 Lexical 在对应位置渲染该组件，而不是直接渲染 DOM 元素。

创建 DecoratorNode

创建 DecoratorNode 需要继承 DecoratorNode 类并实现以下关键方法：

import {$applyNodeReplacement} from 'lexical';
import {DecoratorNode} from 'lexical';
import {ReactNode} from 'react';

class MyDecoratorNode extends DecoratorNode<ReactNode> {
  // 节点的类型标识
  static getType(): string {
    return 'my-decorator';
  }

  // 克隆节点
  static clone(node: MyDecoratorNode): MyDecoratorNode {
    return new MyDecoratorNode(node.__key);
  }

  // 导入 JSON
  static importJSON(serializedNode: any): MyDecoratorNode {
    return $createMyDecoratorNode();
  }

  // 导出 JSON
  exportJSON(): any {
    return {
      type: 'my-decorator',
      version: 1,
    };
  }

  // 返回要渲染的 React 组件
  decorate(): ReactNode {
    return <div>My Decorator Component</div>;
  }
}

// 创建节点的工厂函数
function $createMyDecoratorNode(): MyDecoratorNode {
  return $applyNodeReplacement(new MyDecoratorNode());
}

关键方法

decorate()

这是 DecoratorNode 最核心的方法。它返回一个 React 组件（或其他框架组件）， Lexical 会将该组件渲染在节点对应的位置。 

decorate(): ReactNode {
  return <MyComponent data={this.__data} />;
}

isIsolate()

返回 true 时，该节点会被视为隔离区域，用户无法通过键盘导航进入节点内部。 适用于嵌入整个独立 UI 组件的场景（如日期选择器）。 

isIsolate(): boolean {
  return true;
}

isInline()

返回 true 时，节点会以内联元素形式渲染。

isInline(): boolean {
  return true;
}

使用场景

嵌入图片

class ImageNode extends DecoratorNode<ReactNode> {
  __src: string;
  __altText: string;

  static getType(): string {
    return 'image';
  }

  decorate(): ReactNode {
    return (
      <img
        src={this.__src}
        alt={this.__altText}
        style={{maxWidth: '100%'}}
      />
    );
  }
}

嵌入表格

class TableNode extends DecoratorNode<ReactNode> {
  __rows: string[][];

  static getType(): string {
    return 'table';
  }

  decorate(): ReactNode {
    return (
      <table>
        {this.__rows.map((row, i) => (
          <tr key={i}>
            {row.map((cell, j) => (
              <td key={j}>{cell}</td>
            ))}
          </tr>
        ))}
      </table>
    );
  }
}

嵌入公式编辑器

class EquationNode extends DecoratorNode<ReactNode> {
  __equation: string;

  static getType(): string {
    return 'equation';
  }

  decorate(): ReactNode {
    return <KatexRenderer equation={this.__equation} />;
  }
}

与 React 集成

在 React 项目中使用 DecoratorNode 时，需要确保：

  1. 节点已注册到编辑器配置中
  2. 使用 <LexicalComposer> 提供编辑器上下文
  3. decorate 方法返回的组件可以访问 React 上下文
import {LexicalComposer} from '@lexical/react/LexicalComposer';
import {RichTextPlugin} from '@lexical/react/LexicalRichTextPlugin';

const editorConfig = {
  namespace: 'MyEditor',
  theme: {},
  onError: (error) => console.error(error),
  nodes: [ImageNode, TableNode], // 注册 DecoratorNode
};

function Editor() {
  return (
    <LexicalComposer initialConfig={editorConfig}>
      <RichTextPlugin
        contentEditable={<ContentEditable />}
        placeholder={<div>Enter some text...</div>}
      />
    </LexicalComposer>
  );
}

限制与注意事项

  • 框架绑定：DecoratorNode 需要与特定框架（如 React）绑定使用。 如果需要在无框架环境使用，需要手动管理 DOM 渲染。
  • 序列化：decorate 返回的组件不会被序列化，只有节点的数据模型会被保存。
  • 选区处理：DecoratorNode 内部的选区独立于编辑器选区，需要特殊处理。
  • 性能：复杂的装饰器组件可能影响编辑器性能，建议使用 React.memo 优化。
