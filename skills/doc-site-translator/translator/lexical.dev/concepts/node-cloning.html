Node Cloning

理解如何正确克隆和修改节点对于使用 Lexical 至关重要。本指南解释不同的克隆机制以及何时使用每种机制。

Types of Node Cloning #

Lexical 提供了几种克隆节点的方法，每种都有不同的目的：

  • static clone() - 用于状态管理的内部 API
  • $copyNode() - 用于创建新节点的公共 API
  • getWritable() - 用于节点修改的公共 API

The clone Method #

What is clone? #

static clone() 方法是所有 Lexical 节点所需的静态方法，用于创建节点的下一个版本。然而，重要的是要理解这是 Lexical 状态管理系统使用的内部 API。

class MyCustomNode extends ElementNode {
  static clone(node: MyCustomNode): MyCustomNode {
    // ✅ Correct implementation
    return new MyCustomNode(node.__someData, node.__key);
  }
}

When is clone Used? #

  • 内部状态管理
    • 由 Lexical 内部使用
    • 编辑器状态更新系统的一部分
    • 由 getWritable() 调用
  • 节点修改
// Example of a node method implementation
class MyCustomNode extends ElementNode {
  setData(data: string): this {
    const self = this.getWritable();
    self.__data = data;
    return self;
  }
}

node.setSomeData("new data");

When NOT to Use clone? #

永远不要直接调用 clone() - 使用 $copyNode() 或节点方法代替。

Using $copyNode #

What is $copyNode? #

$copyNode 是用于创建带有新 key 的节点副本的公共 API。当您需要创建重复节点时使用此 API。

默认情况下，所有属性和 NodeState 将被复制到新节点，然后调用 afterCloneFrom 以允许节点可选地将某些属性（以及配置为 equality 的 NodeState）重置为默认值（例如 ListItemNode 的选中状态）。

// ✅ Correct: Using $copyNode
const copy = $copyNode(existingNode);

When to Use $copyNode? #

  • 创建重复项 - 当您需要副本时使用 $copyNode

Using getWritable #

What is getWritable? #

getWritable 是在节点方法实现中使用的内部 API，用于获取节点的可变版本。节点消费者应使用节点的公共方法代替。

// ✅ Correct: Implementation of a node method
class MyCustomNode extends ElementNode {
  setData(data: string): this {
    const self = this.getWritable();
    self.__data = data;
    return self;
  }
}

// ✅ Correct: Using the node
const node = new MyCustomNode();
node.setData("new value");

Common Patterns #

Modifying Nodes #

// ✅ Use node methods
node.setTextContent("new text");

// ❌ Don't directly use getWritable outside of node methods
const writable = node.getWritable();
writable.__text = "new text";

Copying Nodes #

// ✅ Use $copyNode
const copy = $copyNode(node);
someParent.append(copy);

Performance Considerations #

  • 引用完整性
    • getWritable 确保使用新克隆进行正确的 EditorState 更新
    • 防止不会渲染的"孤立"节点
  • 状态管理
class MyCustomNode extends ElementNode {
  setData(data: string): this {
    const self = this.getWritable();
    self.__data = data; // Properly tracked by editor
    return self;
  }
}

Common Questions #

问：如何复制节点？

答：使用 $copyNode 创建带有新 key 的新副本。

问：何时应该使用 clone？

答：永远不要直接使用。使用 $copyNode 或节点方法代替。
