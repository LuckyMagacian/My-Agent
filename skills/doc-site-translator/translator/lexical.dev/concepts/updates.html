Updates

Lexical 中的 Updates 是修改编辑器状态的同步操作（嵌套 update 场景除外，这应该被弃用）。协调过程（DOM 更新）出于性能原因被批量处理。这种 DOM 更新的批处理意味着我们可以避免不必要的重新渲染并优化渲染过程。

Update Tags #

Update tags 是可以附加到 update 以指示其类型或目的的字符串标识符。它们可用于控制 update 如何被处理、合并或由 listener 处理。单个 update 可以使用多个 tag。

您可以通过两种方式添加 tag：

在 editor.update() 中使用 tag 选项：

import {HISTORY_PUSH_TAG, PASTE_TAG} from 'lexical';

editor.update(() => {
  // Your update code
}, {
  tag: HISTORY_PUSH_TAG // Single tag
});

editor.update(() => {
  // Your update code
}, {
  tag: [HISTORY_PUSH_TAG, PASTE_TAG] // Multiple tags
});

在 update 中使用 $addUpdateTag() 函数：

import {HISTORY_PUSH_TAG} from 'lexical';

editor.update(() => {
  $addUpdateTag(HISTORY_PUSH_TAG);
  // Your update code
});

您可以使用 $hasUpdateTag() 检查 tag 是否存在：

import {HISTORIC_TAG} from 'lexical';

editor.update(() => {
  $addUpdateTag(HISTORIC_TAG);
  console.log($hasUpdateTag(HISTORIC_TAG)); // true
});

注意：虽然 update tag 可以使用 $hasUpdateTag() 在同一 update 中检查，但它们通常通过各自 payload 中的 tags 和 updateTags 属性在 update 和 mutation listener 中访问。以下是更常见的使用模式：

import {HISTORIC_TAG} from 'lexical';

editor.registerUpdateListener(({tags}) => {
  if (tags.has(HISTORIC_TAG)) {
    // Handle updates with historic tag
  }
});

editor.registerMutationListener(MyNode, (mutatedNodes, { updateTags }) => {
  // updateTags contains tags from the current update
  if (updateTags.has(HISTORIC_TAG)) {
    // Handle mutations with historic tag
  }
});

常用 Update Tags #

Lexical 提供了几个作为常量导出的内置 update tags：

  • HISTORIC_TAG: 表示 update 与历史操作（undo/redo）相关
  • HISTORY_PUSH_TAG: 强制创建新的历史条目
  • HISTORY_MERGE_TAG: 将当前 update 与上一个历史条目合并
  • PASTE_TAG: 表示 update 与粘贴操作相关。@lexical/history 将此视为历史边界，因此粘贴获得自己的撤销条目
  • CUT_TAG: 表示 update 与剪切操作相关。@lexical/history 将此视为历史边界，因此剪切获得自己的撤销条目
  • COLLABORATION_TAG: 表示 update 与协作编辑相关
  • SKIP_COLLAB_TAG: 表示 update 应跳过协作同步
  • SKIP_SCROLL_INTO_VIEW_TAG: 防止将 selection 滚动到视图中
  • SKIP_DOM_SELECTION_TAG: 防止更新 DOM selection（对于不应影响 focus 的 update 很有用）

Tag 验证 #

为了防止拼写错误并在使用 update tags 时确保类型安全，Lexical 为所有内置 tag 导出常量。建议始终使用这些常量而不是字符串字面量：

import {
  HISTORIC_TAG,
  HISTORY_PUSH_TAG,
  COLLABORATION_TAG,
} from 'lexical';

editor.update(() => {
  // Using constants ensures type safety and prevents typos
  $addUpdateTag(HISTORIC_TAG);

  // These constants can be used in update options
  editor.update(() => {
    // Your update code
  }, {
    tag: HISTORY_PUSH_TAG
  });

  // And in listener checks
  editor.registerUpdateListener(({tags}) => {
    if (tags.has(COLLABORATION_TAG)) {
      // Handle collaborative updates
    }
  });
});

自定义 Tags #

虽然 Lexical 提供常用 tag 作为常量，但您也可以定义自己的常量用于自定义 tag，以保持一致性和类型安全：

// Define your custom tags as constants
const MY_FEATURE_TAG = 'my-custom-feature';
const MY_UPDATE_TAG = 'my-custom-update';

editor.update(() => {
  $addUpdateTag(MY_FEATURE_TAG);
}, {
  tag: MY_UPDATE_TAG
});

// Listen for updates with specific tags
editor.registerUpdateListener(({tags}) => {
  if (tags.has(MY_FEATURE_TAG)) {
    // Handle updates from your custom feature
  }
});
