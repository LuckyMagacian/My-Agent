Read Mode / Edit Mode

Lexical 支持两种模式：

  • Read mode（只读模式）
  • Edit mode（编辑模式）

Lexical 的默认行为是编辑模式，或者更准确地说，不是只读模式。在底层，主要实现细节是根据模式将 contentEditable 设置为 "false" 或 "true"。特定插件也可以监听模式更改，允许它们根据模式自定义 UI 的部分。

设置模式 #

要设置模式，可以在创建编辑器时完成：

const editor = createEditor({
  editable: true,
  ...
})

如果您使用 @lexical/react，可以在传递给 <LexicalComposer> 的 initialConfig 中完成：

<LexicalComposer initialConfig={{editable: true}}>
  ...
</LexicalComposer>

编辑器创建后，可以命令式地更改模式：

editor.setEditable(true);

读取模式 #

要查找编辑器的当前模式，可以使用：

const isEditable = editor.isEditable(); // 返回 true 或 false

您也可以在编辑器的只读模式更改时收到通知：

const removeEditableListener = editor.registerEditableListener(
  (isEditable) => {
    // 编辑器的模式在这里传入！
    console.log(isEditable);
  },
);

// 不再需要时不要忘记取消注册 listener！
removeEditableListener();
