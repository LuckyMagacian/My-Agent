@lexical/table

此包包含 Lexical 表格功能的相关实现。

Lexical 表格插件

用于在 Lexical 中处理表格的插件。

安装​

npm install @lexical/table @lexical/react

使用​

请参阅 react-table 示例，这是一个使用此包以及 @lexical/react/LexicalTablePlugin 中 TablePlugin 的最小示例。

功能​

表格​

  • 创建和编辑具有可自定义行列的表格
  • 支持表头
  • 单元格选择和导航
  • 复制和粘贴支持

限制​

嵌套表格​

编辑器不支持嵌套表格（表格单元内的表格）。强制执行以下行为：

  1. 尝试在现有表格单元内粘贴表格时，粘贴操作会被阻止。
  2. 编辑器会主动阻止通过 UI 或编程方式创建嵌套表格。

注意：当粘贴包含嵌套表格的 HTML 内容时，嵌套内容默认会被移除。如果需要以某种形式保留这些内容，请确保实现适当的 importDOM 处理。

这种方法允许你：

  1. 检测导入 HTML 中的嵌套表格
  2. 在内容被移除之前提取其内容
  3. 以适合你用例的格式保留内容

选择最适合你需求的方法：

  • 将嵌套表格扁平化为单个表格
  • 将嵌套表格转换为其他格式（如列表或段落）
  • 将嵌套内容存储为元数据以供后续处理
