## 翻译说明

### 保留英文的内容

- 所有包名（如 `@lexical/react`、`@lexical/rich-text`）
- 所有函数名、类名、方法名、API 名称
- 所有代码块内容
- 技术术语：editor, state, node, plugin, component, hook, command 等

### 翻译的内容

- 页面标题和描述性文本
- 章节标题
- 代码注释（翻译为中文）
- UI 文本（导航、面包屑等）
