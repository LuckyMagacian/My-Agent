内置扩展

@lexical/clipboard

  • ClipboardDOMImportExtension - 通过 DOMImportExtension 管道路由 text/html 粘贴和拖放（实验性）
  • ClipboardImportExtension - 可配置的按 MIME 类型的剪贴板导入，用于粘贴和拖放（实验性）
  • GetClipboardDataExtension - 可配置的选区序列化为剪贴板 MIME 类型，用于复制和拖动

@lexical/code

  • CodeExtension - CodeNode（代码块）
  • CodeIndentExtension - CodeNode Tab 键缩进（代码块）

@lexical/code-prism

  • CodePrismExtension - 使用 Prism 为 CodeNode 提供语法高亮

@lexical/code-shiki

  • CodeShikiExtension - 使用 Shiki 为 CodeNode 提供语法高亮

@lexical/dragon

  • DragonExtension - Dragon（语音转文字）支持，默认包含在 RichTextExtension 和 PlainTextExtension 中

@lexical/extension

  • AutoFocusExtension - 创建编辑器时自动聚焦（例如页面加载时）
  • ClearEditorExtension - CLEAR_EDITOR_COMMAND 的实现
  • ClickAfterLastBlockExtension - 在无法容纳点击的最后一个块（例如 DecoratorNode 或 TableNode）下方点击时插入段落
  • DecoratorTextExtension - DecoratorTextNode 支持，设置 DOM 容器的格式和 CSS 类
  • EditorStateExtension - 提供 EditorState 作为 signal（替代 registerUpdateListener）
  • HorizontalRuleExtension - HorizontalRuleNode（<hr> 标签）
  • IMEExtension - 将 IME 组合状态集中为 signals
  • InitialStateExtension - 设置编辑器的初始状态（始终包含）
  • NestedEditorExtension - 将编辑器配置为父编辑器的嵌套编辑器（主题继承，可选的可编辑状态）
  • NodeSelectionExtension - 跟踪选区，通常用于 DecoratorNodes
  • NormalizeInlineElementsExtension - 移除空的内联元素，默认包含在 RichTextExtension 和 PlainTextExtension 中
  • NormalizeTripleClickSelectionExtension - 修正三击事件后的过度选择，默认包含在 RichTextExtension 和 PlainTextExtension 中
  • PreventSelectAllExtension - 防止 input/textarea 元素内的全选（Ctrl/Cmd+A）选中编辑器内容，默认包含在 SelectBlockExtension 中
  • SelectBlockExtension - 全选（Ctrl/Cmd+A）首先选择最近的块元素，再次按下选择整个文档
  • SelectionAlwaysOnDisplayExtension - 即使编辑器未聚焦也高亮显示选中的内容
  • TabIndentationExtension - 更改 Tab 键行为，插入制表符和缩进，而不是原生地聚焦下一个字段
  • WatchEditableExtension - 将编辑器的可编辑状态公开为响应式 Signal<boolean>

@lexical/hashtag

  • HashtagExtension - HashtagNode

@lexical/history

  • HistoryExtension - 历史支持（撤销/重做）
  • SharedHistoryExtension - 父编辑器与其嵌套编辑器之间的历史共享

@lexical/html

  • CoreImportExtension - 核心节点的 DOM 导入规则，由提供节点的扩展隐式包含（实验性）
  • DOMImportExtension - 基于 Extension 的 importDOM/DOMConversion 替代方案，规则在编辑器构建时编译到调度器中（实验性）
  • DOMRenderExtension - 覆盖编辑器的 DOM 渲染和导出行为（实验性）

@lexical/link

  • AutoLinkExtension - AutoLinkNode，注意匹配器需要手动配置
  • ClickableLinkExtension - 在 lexical 选区和原生点击打开链接行为之间切换
  • LinkExtension - LinkNode（<a> 标签）

@lexical/list

  • ListExtension - ListNode, ListItemNode
  • CheckListExtension - ListNode 和 ListItemNode 的清单支持

@lexical/mark

  • MarkExtension - MarkNode

@lexical/overflow

  • OverflowExtension - OverflowNode

@lexical/plain-text

  • PlainTextExtension - 纯文本编辑器，回车键默认创建 LineBreakNode（每个文档一个 ParagraphNode）

@lexical/react

  • ReactExtension
  • ReactPluginHostExtension
  • ReactProviderExtension
  • TreeViewExtension

@lexical/rich-text

  • RichTextExtension - 富文本编辑器（QuoteNode, HeadingNode），回车键默认创建 ParagraphNode（每个文档多个 ParagraphNode）。包含可配置的 escapeFormatTriggers 用于在文本节点边界处转义文本格式（例如代码）

@lexical/table

  • TableExtension - TableNode, TableRowNode, TableCellNode

@lexical/tailwind

  • TailwindExtension - 使用 Tailwind 类的主题配置
