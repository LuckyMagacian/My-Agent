Peer 依赖

Peer Dependencies 用于声明扩展之间的间接或可选依赖。这可用于仅在某个其他扩展可用时启用某些功能或配置，或用于避免依赖循环。扩展必须形成有向无环图，不能存在从一个扩展回到其自身的依赖路径。

使用场景​

通常，peerDependencies 的预期使用场景是仅在某个其他扩展存在时提供功能。例如，你可能有一个需要特殊代码与 React 交互的扩展，但它也可以在没有 React 的情况下使用，因此你可以将 ReactProviderExtension 放在 peerDependencies 数组中。

另一个例子是为提供某种自定义节点类型的扩展提供 Markdown 序列化或导入功能，但仅当该编辑器中存在 MarkdownExtension 时才提供。
