集成 Tiptap UI 组件

Tiptap 是无头（headless）且模块化的，让你对 UI 拥有完全控制权。Tiptap UI 组件库提供了预构建的界面，因此你不必从零开始构建所有内容。可以直接使用，也可以根据你的设置进行自定义。

React 19 与框架兼容性

我们目前正在升级对 React 19 及更新框架版本的支持。某些组件可能尚未完全兼容。目前，UI 组件与 React 18（以及对应的框架版本如 Next.js 15）配合使用效果最佳。我们会在新版本完全支持后更新此页面。

许可证与源代码

Tiptap UI 组件遵循与其所基于的编辑器扩展相同的许可证。

  • 如果扩展是开源的（如 Bold、Heading 或 Image），则 UI 组件同样采用 MIT 许可证。
  • 你可以自由阅读源代码、复制并按需自定义。

某些组件是为付费 Tiptap 功能构建的，如 Comments 或 Version History。

  • 这些组件不是开源的。
  • 大多数包含依赖 Tiptap 后端服务的前端逻辑。
  • 使用 Tiptap Cloud 订阅或试用才能使用它们。

无论哪种类型（免费或云端连接），你都可以检查源代码并根据你的用例进行适配。

组件的安装方式

Tiptap UI 组件不作为 npm 包发布。CLI 将它们以源代码文件的形式复制到你的项目中，你拥有并可以编辑这些文件：

npx @tiptap/cli@latest add <component>

每个组件还会自动引入它所依赖的其他组件、hooks、图标、库和样式。这就是为什么已安装组件的导入（例如 @/components/tiptap-node/image-node/image-node-extension）会解析为你自己代码库中的文件，而不是 node_modules 中的模块。要获取这些页面上演示所使用的所有内容，请使用上述命令安装该组件或模板；每个组件页面在引用的组件下列出了其引用的文件。

设计默认值

组件被设计为原生的感觉，能融入你的设计。它们带有中性样式：最少的颜色、基本的间距，没有强烈的视觉倾向。你可以直接使用，也可以自定义以匹配你的品牌。

设计在所有组件之间保持一致和协调，因此如果你同时使用多个组件，它们无需额外工作就能很好地搭配。

  • 无需复杂的覆盖或 !important hack
  • 直接编辑代码，因为它就是为分叉或扩展而设计的

组件与原语

要在 Tiptap 编辑器中构建出色的编辑体验，你可以集成 UI 元素。该库为此提供了不同类型的构建块：组件、节点组件和原语。

组件

即用型、功能特定的 React 组件，例如标题下拉菜单。每个 UI 组件通常与一个 Tiptap 扩展配对（例如，ListButton 依赖于列表相关扩展），并使用 React hooks 与编辑器状态交互。

  • 与扩展配合使用：要使用组件（例如 HeadingDropdownMenu），请确保在编辑器中启用了匹配的 Tiptap 扩展（如 @tiptap/extension-heading）。
  • 利用 hooks：许多组件内部使用 hooks（如 useTiptapEditor 或 useFloatingElement）来同步编辑器状态、处理定位或管理键盘导航。你也可以在自己的自定义组件中使用这些 hooks。
  • 轻松自定义：默认情况下，这些组件具有最少的样式，以便融入你的设计。你可以完全覆盖或扩展它们。每个组件的源代码公开可用，可直接编辑，无需 !important hack。

原语

底层 UI 元素，如 Button、DropdownMenu、Popover 和 Spacer。它们是许多 UI 组件的基础，处理可访问性和基本行为。你可以混合搭配这些原语来创建自己的编辑器控件，或进一步自定义现有组件。
